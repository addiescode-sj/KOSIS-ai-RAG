## Idea
1. **L4 §6.3 정답 표**:
   - `run_e2e`가 `--golden`(L1)을 함께 읽는다. qid가 같은 L1 문항이 있으면, L1 채점기(`retrieval.first_rank`·정답 슬롯 키)로 `right_table`을 판정한다(리뷰 3: 따로 짜지 않고 재사용).
   - L1 문항이 없으면(v1 L3 90문항) 지금처럼 대표 표로 판정하고, 리포트에 "L1 연결 n"을 적는다.
   - "대체 표로 맞힘"은 따로 센다.
2. **L4 §6.3 연도·지역**:
   - `{연도}`: `StatAnswer.query.periods`를 L2 `period_start..period_end`와 대조한다.
   - `{지역}`: `filters` 값을 시도 정식 이름으로 바꿔 L2 `regions`와 대조한다. L2는 같은 qid로 연결한다(`--query-golden`).
   - 둘 다 L1 연결이 있는 문항만 잰다. **담당은 AI 파이프라인**이다(StatQuery는 summarize_stat의 질의 분석, 리뷰 1a).
3. **§4.3 no_period 거절률**:
   - L1 리포트: 사유별(no_period·no_item·out_of_scope) 답 없음 재현율.
   - L4 리포트: `allowed_reasons`에 `no_period`가 있는 `not_answerable` 문항의 거절률과 사유 일치율(리뷰 1c).
4. **L2 P/R (§5)**: `regions`·`dimensions`·`years`에 미시 평균 P/R을 집합 일치와 함께 낸다. `measures`는 파서가 개념어를 검색어로 늘리는 부분집합 규칙이라 P/R을 내지 않는다(리뷰 2).
5. **"고칠 담당" 요약**: 각 리포트 첫머리에 실패 수를 담당별로 묶는다.
   - L0 미매핑·불일치, L2 오답 필드(필드별) → 데이터 (`parse_query`·메타데이터, T2-14·T2-30).
   - L1 순위·답 없음 판정 → AI 파이프라인 (검색·리랭커, T2-06·07·09).
   - L3 오류 유형, L4 answer·연도·지역 → AI 파이프라인 (summarize_stat).
   - L4 retrieval → AI 파이프라인(검색). 단, L1 필터 recall이 떨어진 문항은 데이터로 돌린다.
6. **걷어 내기**: 난도 지표 3개 함수와 meta 필드만 지운다. 이미 만든 v2 파일은 문장·슬롯이 그대로이므로 다시 만들지 않는다.
7. pytest: 새 채점 규칙마다 oracle 1.000 + 대표 실패 한 가지씩.

범위 밖 (리뷰 1b, 3):
- L0 regions·cycle·available_years 미매핑: 정규화 사전 계약(KOS-97)이 아직 없다.
- L0 적재 값 대조: 공유 Chroma 서버가 켜져 있어야 실측된다.
