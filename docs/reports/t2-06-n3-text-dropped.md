# n3 표 텍스트 폐기, 조건 슬롯은 유지 (2026-11-03, 전민기 결정)

관련: `plans/T2-06.md`, `plans/T2-07.md`(2026-11-02 범위 변경의 되돌림), `src/kosis_rag/text.py`.

## 1. 결정

- **폐기:** 검색용 표 텍스트 `n3-L60`(n2 카드 + `세는 대상`·`분류`·`단위` 줄 + 지역 분류를 라벨 대신 단위 요약으로 쓰는 것). 미세조정 임베딩·리랭커·BM25·HCX 2차 카드 모두 **`n2-L60`으로 되돌린다.** `kosis_rag.text.DOC_FORMAT = "n2-L60"`.
- **유지:** 조건 슬롯(질문 → 연도·기간·주기·시도, 표 → 수록 연도·주기·지역 수준·분류)과 그 재료인 T2-25 `levels`, T2-27 `roles`, T2-30 `vocab`·`TableFields`. 슬롯은 표 텍스트가 아니라 `TableRecord`에서 직접 읽으므로 이번 결정의 영향을 받지 않는다.

한 줄로: **"정규화한 사실은 슬롯·메타데이터·평가로 쓰고, 임베딩 텍스트에는 넣지 않는다."**

## 2. 근거 (lab 측정, 검색 골든 89문항 · 라우팅 골든 208문항)

| 비교 (같은 학습 데이터 v0, 1에폭) | Hit@1 | Hit@5 | Hit@10 | MRR |
| --- | --- | --- | --- | --- |
| n2 텍스트: dense만 | .337 | .596 | .697 | .460 |
| n3 텍스트: dense만 | .326 | .640 | .753 | .469 |
| n2 텍스트: dense + BM25 융합 | **.416** | .596 | .708 | **.514** |
| n3 텍스트: dense + BM25 융합 | .348 | .607 | .685 | .474 |
| n3 dense + n2 BM25 (가정) | .337 | .607 | .697 | .466 |

- 학습하지 않은 bge-m3에서도(계획 53) 학습한 뒤에도 n3가 n2를 유의하게 이긴 지표가 없다. 융합 MRR은 n2 대비 −.040 [−.082, +.001], 가정 융합은 −.048 [−.086, −.014]. 라우팅 test는 차이 없음.
- n3의 dense 재현율(Hit@5·10)은 조금 낫지만 1위 정확도가 떨어진다. BM25를 n2로 되돌려도 회복되지 않으므로 원인은 BM25 쪽이 아니다.
- **원인:** 덧붙인 줄은 이름이 같거나 비슷한 **형제 표에 똑같이 붙는 상수**다. 가족을 찾는 힘은 그대로인데 가족 안에서 기간·주기·지역 수준이 다른 형제를 가르는 힘이 줄었다. 1위를 잃은 8문항 중 6문항이 형제 뒤바뀜(1위 → 2~3위)이다. 예: "최근 1년간 월별 외국인 입국자 수"(2010~2025 표 → 1993~2009 표), "외국인주민 현황 2010년 1월 1일 기준"(2007~2015 표 → 2006 표), "2025년 2분기 사망자 수"(분기 표 → 연간 표). 같은 이름 가족의 표끼리 코사인 평균 .854 → .873.
- 질문 유형별 융합 Hit@1: 정확한 이름 9 → 10, 형제 표 10 → 8, 기간·주기 5 → 1.
- 텍스트 생성 버그는 없었다(설계대로 생성). 손실 문항은 **조건 슬롯이 맡을 기간·주기·지역 조건**이라 텍스트를 더 바꿔서 풀 문제가 아니다.

## 4. 후속 작업 규칙 (괴리 방지)

1. **새 정규화 결과(세는 대상, 분류 표준 이름, 단위, 지역 수준)는 메타데이터·슬롯·평가로 연결한다.** `text.py`의 임베딩 텍스트에 줄로 넣지 않는다. 텍스트를 바꾸려면 새 형식 이름(`n4-…`)을 만들고 n2와 같은 학습·평가(검색 골든 짝 비교, 1위 기준 포함)로 이겨야 기본이 된다.
2. `roles.py`·`vocab.py`·`metadata.py`를 고칠 때 확인할 곳은 **필터·메타데이터·평가기**다(`filters.py`, `index.to_metadata`, `evals`). 표 텍스트와 미세조정 가중치는 영향받지 않는다(n2는 이 모듈을 쓰지 않음).
3. 기간·주기·지역 수준이 다른 형제 표를 가르는 일은 **조건 슬롯(필터·감점)과 리랭커**의 몫이다. 형제 뒤바뀜 문항은 슬롯 쪽 개선 대상으로 올린다.
4. 컬렉션 메타데이터 `doc_format`과 가중치 옆 `.json`의 `doc_format`이 다르면 로딩이 거부된다(`model.check_format`). 새로 만들 때는 둘 다 `n2-L60`.

## 5. 전환 절차 (서비스·평가 환경)

```cmd
set PYTHONPATH=.;src;vendor/phase1;vendor/phase1/src
python -m kosis_rag.index --model bge-m3-ft --text-format n2-L60 --ckpt data\models\<n2 v0 임베딩 가중치>.pt
```

`.env`: `CHROMA_COLLECTION`을 새 컬렉션으로, `EMBED_CKPT`는 n2 가중치, `RERANK_CKPT`는 지금의 n2 리랭커 그대로, `TEXT_FORMAT=n2-L60`(선택, 불일치 검사용). n3 컬렉션을 쓰던 `.env`는 TEXT_FORMAT 검사에 걸리므로 함께 바꾼다.
