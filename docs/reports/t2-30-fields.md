- `measure`는 표 이름이 "A/B/C별 X" 꼴이 아닌 표에서 비워 둔다(T2-27).

## 2. 단위 (`measure_unit`)

표 단위가 없으면 항목 이름 끝 괄호를 아래 목록으로 읽고, **모든 항목이 같은 단위일 때만** 채운다. 괄호 없는 항목이 %·금액일 수 있어 일부 항목에만 단위가 있는 표는 비워 둔다.

- 인정 단위: % · ㎡ · 가구 · 개 · 개월 · 건 · 만원 · 명 · 명/㎢ · 세 · 세대 · 쌍 · 원 · 천명당 · 천원 · 호

| 출처 | 표 수 |
| --- | ---: |
| 표 단위 | 1,473 |
| 없음: 단위 정보 없음 | 716 |
| 항목 이름 (모든 항목 같은 단위) | 100 |
| 없음: 일부 항목에만 단위 | 43 |
| 없음: 항목마다 단위가 다름 | 32 |

단위로 보지 않은 끝 괄호 상위 값(KOS-97 단위 사전에서 다시 본다): 15세 이상 25, 60세 이상 16, 15세이상 15, 5세 이상 11, 여자백명당남자수 11, 중풍 포함 9, 치매 포함 9, 65세 이상 9, 예체능 포함 8, 12세이상 6, 친가외가 5, 일시 휴직 포함 5

## 3. KOS-92 확인 — 같은 단어가 세는 대상과 분류 기준에 섞인 표

| 단어 | 표 이름에 든 표 | 세는 대상(`measure`)에 있음 | 분류(`dimensions`)에만 있음 | 둘 다 없음 | (measure, dimensions) 조합 수 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 출생 | 146 | 32 | 103 | 11 | 91 |
| 혼인 | 241 | 39 | 183 | 19 | 139 |

세는 대상 표와 분류 역할 표가 `measure` 한 필드로 갈린다. "둘 다 없음"은 표 이름 꼴이 맞지 않아 measure가 비고 분류 이름에도 그 단어가 없는 표다.

## 4. 멘토 예시 표 — 이동자유형별 인구 (목록 `A11_2015_1_10`)

`101_DT_1PB1607` 현 거주지 성, 연령 및 1년 전 거주지 기준 이동자유형별 인구(1세이상) - 읍면동(연도 끝자리 0, 5), 시군구(그 외 연도)

| 필드 | 값 |
| --- | --- |
| `key` | 101_DT_1PB1607 |
| `available_years` | 2016~2025 (10개 해) |
| `cycle` | Y |
| `regions` | 17개 (강원특별자치도, 경기도, 경상남도 …) |
| `region_level` | 시군구, 시도, 읍면동 |
| `measure` | 인구 |
| `measure_unit` | 명 |
| `dimensions` | 현 거주지 성, 연령, 1년 전 거주지 기준 이동자유형 |

- `dimensions`의 "현 거주지 성"은 표 이름의 "현 거주지 성, 연령 및 …"을 쉼표로 나눈 결과다. "현 거주지"(지역)와 "성"이 붙어 나온다. 이런 이름은 KOS-97 분류명 정규화에서 나눈다.
- 표 이름의 "읍면동(연도 끝자리 0, 5), 시군구(그 외 연도)"는 `region_level`과 `available_years`로는 "읍면동은 2020·2025년만"을 나타내지 못한다(6절).

## 6. 알려진 한계

- 지역 단위별 수록 연도가 다른 표(예: 읍면동은 연도 끝자리 0·5만, 그 외 해는 시군구까지)는 표 단위 `available_years` 하나로 구분하지 못한다. 표 이름에 드러난 표는 5개다. Parquet 값에서 단위별 연도를 읽는 일은 A7 또는 별도 이슈로 넘긴다.
- `dimensions`는 표가 쓴 이름 그대로다(시도별·행정구역별(시도) 등). 표준 이름으로 묶는 것은 KOS-97이다.
